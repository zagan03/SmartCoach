# SmartCoach — User Stories

## Epic 1: Authentication & Onboarding

**US-001**
> As a new user, I want to log in quickly with a demo account, so that I can try the app without registering.

**US-002**
> As a returning user, I want my session to persist between page refreshes, so that I don't have to log in every time.

**US-003**
> As a new user, I want to create my fitness profile through a guided 3-step wizard, so that the app can personalise my recommendations.

**US-004**
> As a user, I want to edit my profile at any time, so that the app recalculates my goals when my stats change.

---

## Epic 2: Weight Tracking

**US-005**
> As a user, I want to record my daily weight, so that I can track my progress over time.

**US-006**
> As a user, I want to see my weight history as a chart, so that I can visually identify trends and progress toward my target.

**US-007**
> As a user, I want to edit or delete past weight entries, so that I can correct mistakes without losing my data.

**US-008**
> As a user, I want to see my current BMI on the dashboard, so that I have a quick health indicator at a glance.

---

## Epic 3: Workout Tracking

**US-009**
> As a user, I want to log a workout session with multiple exercises, so that I can keep a complete training history.

**US-010**
> As a user, I want to specify sets, reps, and weight for strength exercises (or duration/distance for cardio), so that my logs are accurate.

**US-011**
> As a user, I want to browse my past workouts in an expandable list, so that I can review and learn from my training history.

**US-012**
> As a user, I want to edit or delete a workout session, so that I can correct errors or remove duplicates.

---

## Epic 4: AI Agents

**US-013**
> As a user, I want the Nutrition AI agent to analyse my recent weight progress and recommend a calorie adjustment, so that my diet stays on track with my goals.

**US-014**
> As a user, I want the Workout Coach AI agent to generate a personalised training plan based on my goal and fitness level, so that I know exactly what to do in the gym.

**US-015**
> As a user, I want the AI agents to work even without a third-party API key, so that the app always provides a useful response during demos.

**US-016**
> As a user, I want the AI agents to never recommend dangerous calorie levels, so that my safety is protected even if I set unrealistic goals.

---

## Epic 5: Dashboard & Overview

**US-017**
> As a user, I want to see my BMR, TDEE, and daily calorie target on the dashboard, so that I understand the science behind my recommendations.

**US-018**
> As a user, I want to see a consistency streak badge showing how many consecutive days I've been active, so that I stay motivated.

**US-019**
> As a user, I want the dashboard to show my latest weight entry and last workout at a glance, so that I can quickly resume where I left off.

**US-020**
> As a user, I want to navigate between all sections from a persistent sidebar/bottom nav, so that the app feels intuitive and fast.
